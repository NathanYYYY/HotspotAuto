移动热点自动开启（HotspotAuto）使用说明
========================================

一、安装（只需一次）
1. 把压缩包解压到任意文件夹（不要只放在压缩包里运行）。
2. 双击 HotspotAuto.exe。
   如果 Windows 提示“已保护你的电脑”，点“更多信息 → 仍要运行”
   （程序没有数字签名）。
3. 点“安装开机自启”，看到“开机自启：已安装”即可。

以后每次开机，热点会自动开启；在锁屏/登录界面就已经开好。
程序会检查约 1 分钟，确认热点稳定后自动退出，不会一直挂在进程里；
退出后热点由 Windows 保持开启。
本工具不会绕过 Windows 登录密码，也不会自动登录。

二、日常使用
- 双击 HotspotAuto.exe 可以查看状态、手动开启、打开系统热点设置。
- 改热点名称/密码：设置 → 网络和 Internet → 移动热点。
- 卸载：双击“卸载开机自启.bat”，或在程序里点“卸载开机自启”。

三、如果关机再开机后热点没自动开
Windows 11 默认“快速启动”可能不触发开机任务。双击“关闭快速启动.bat”
（需要管理员），下次关机再开即可；或者用“重启”代替“关机”。
想改回来，双击“恢复快速启动.bat”。

四、日志
C:\ProgramData\HotspotAuto\hotspot.log

五、常见问题
- 程序会一直在后台吗？不会。每次开机只运行约 1 分钟，然后自动退出。
- 热点开了但手机不能上网：检查电脑本身的网络是否通；程序只在启动后的
  1 分钟内自动重试，之后需要手动处理。
- 安装/卸载时可能弹一次 UAC，允许即可。
- 任务计划程序里的任务名是 HotspotAuto，需要管理员权限才能看到。
